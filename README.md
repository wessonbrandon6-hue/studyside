# StudySide ✳

A simple student dashboard to keep study tasks, focus sessions, and study support in one place.

## Features

- **Task tracker** — add tasks and mark them complete
- **Focus sprint** — a 25-minute Pomodoro timer with a five-minute break
- **Study assistant demo** — quick canned prompts for study planning, explanations, quizzes, and getting started
- **Responsive layout** — designed for desktop, tablet, and mobile screens

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Important note

The assistant is currently a front-end demo with preset responses. It is not connected to an AI model or backend, and task/timer data is not saved between browser sessions.

## Built with

HTML, CSS, and vanilla JavaScript.
